RAK BACA - Pembaca dokumen universal (kode sumber lengkap)

Isi folder:
  rak-baca.html   Aplikasi siap pakai dalam satu file (sekitar 2,5 MB). Buka dengan Chrome, Edge,
                  atau Firefox versi baru. Tidak perlu internet dan tidak perlu dipasang; boleh
                  disalin ke flashdisk atau dikirim ke komputer lain.
  src/            Kode sumber (HTML/CSS + JavaScript). Gabungkan dengan tools/build.sh.
  vendor/pdfjs/   pdf.js dari Mozilla (lisensi Apache-2.0) untuk membaca PDF, ikut disatukan
                  ke dalam rak-baca.html. Perbarui dengan tools/update-pdfjs.sh <versi>.
  tools/          build.sh (menyatukan src + pdf.js menjadi rak-baca.html dan desktop/app/index.html),
                  make-samples.js (membuat dokumen contoh semua format),
                  test-reader.js (uji menyeluruh di Chrome: tampilan, keamanan, navigasi,
                  pencarian, penanda, penyimpanan, bacakan),
                  update-pdfjs.sh (mengganti versi pdf.js).
  desktop/        Proyek aplikasi desktop (Electron) + installer Windows.

Format yang bisa dibaca:
  Buku elektronik  EPUB (2 & 3), MOBI/PRC/AZW (tanpa DRM), FB2 (juga .fb2.zip)
  Dokumen          PDF (termasuk PDF berkata sandi dan PDF hasil pindaian JBIG2/JPEG2000),
                   DOCX (Word), ODT (LibreOffice), RTF
  Teks             TXT (UTF-8, UTF-16, Windows-1252), Markdown, HTML, CSV/TSV (tabel),
                   JSON, XML, log, dan berkas kode program
  Gambar & komik   JPG, PNG, WEBP, GIF, BMP, SVG, AVIF, CBZ (komik), ZIP berisi satu dokumen
  Belum didukung   DOC/XLS/PPT lama, XLSX, PPTX, CBR (RAR), AZW3/KF8, MOBI berkompresi HUFF/CDIC,
                   buku ber-DRM. Simpan ulang sebagai PDF/DOCX/EPUB lalu buka lagi.

Cara pakai:
  - Klik "Buka dokumen" atau seret berkas ke jendela. Beberapa berkas sekaligus juga bisa.
  - Dokumen tersimpan di rak beserta posisi baca terakhir, penanda, dan sampulnya.
  - Tombol di bilah atas: Daftar isi, Cari, Penanda, Bacakan (suara), Aa (tampilan), Layar penuh.
  - Tampilan teks (EPUB, DOCX, TXT, ...): tema terang/sepia/gelap, huruf serif/sans/mono,
    ukuran huruf, spasi baris, lebar teks, rata kanan-kiri, dan tata letak 1 kolom (bawaan),
    2 kolom berdampingan di layar lebar, atau Gulir. Tombol C mengganti 1/2 kolom. Posisi baca tetap walau ukuran huruf diubah.
  - Tampilan PDF/komik: gulir atau per halaman, Otomatis / Pas lebar / Pas halaman / 100%,
    Ctrl + roda tetikus atau cubit dua jari untuk memperbesar, halaman gelap pada tema gelap.
  - Catatan kaki terbuka sebagai jendela kecil. Setelah melompat lewat tautan atau daftar isi,
    tombol "Kembali ke posisi tadi" muncul sebentar.
  - Pencarian mengabaikan huruf besar/kecil dan tanda aksen; Enter = hasil berikutnya.
  - Terjemahkan ke bahasa Inggris (tombol bertanda bahasa atau tombol E): menerjemahkan teks
    yang dipilih, atau seluruh halaman yang sedang tampil bila tidak ada teks yang dipilih.
    Memakai penerjemah bawaan Google Chrome 138+ di komputer: berjalan di perangkat, tanpa
    mengirim teks ke internet (model bahasa diunduh Chrome satu kali). Di peramban lain dan di
    aplikasi desktop, tersedia tombol "Buka di Google Terjemahan" yang mengirim teks ke Google
    dan butuh internet; tombol itu hanya berjalan bila diklik.

Pintasan keyboard di layar baca:
  Panah kanan/kiri, PageDown/PageUp, Spasi   halaman berikutnya / sebelumnya
  Home / End                                 awal / akhir dokumen
  Ctrl+F atau /                              cari
  T  daftar isi      B  tandai halaman      R  bacakan      F  layar penuh
  E  terjemahkan ke bahasa Inggris
  M  mode fokus (sembunyikan bilah)          C  ganti 1 kolom / 2 kolom          + / -  ukuran huruf atau perbesaran
  Esc                                        tutup panel, lalu kembali ke rak
  Di rak: Ctrl+O membuka berkas, / ke kotak pencarian.

Penyimpanan & privasi:
  - Semua dokumen dibaca di perangkat ini dan tidak ada yang dikirim ke internet. Halaman
    memakai Content-Security-Policy yang melarang dokumen memuat apa pun dari internet
    (gambar, skrip, font, pelacak). Tautan luar hanya terbuka bila diklik.
  - Salinan dokumen disimpan di penyimpanan peramban (IndexedDB). Peramban lain atau mode
    penyamaran punya rak sendiri. Menghapus data situs/riwayat peramban juga menghapus rak.
    Berkas asli di komputer tidak pernah diubah; "Hapus dari rak" hanya menghapus salinannya.
  - Aplikasi desktop menyimpan rak di folder data aplikasi:
      Windows  %APPDATA%\Rak Baca
      Linux    ~/.config/Rak Baca
  - Isi dokumen dibangun ulang dari daftar elemen yang aman: skrip, iframe, formulir, event
    handler, tautan javascript:, dan gaya berbahaya dari dokumen selalu dibuang.

Aplikasi desktop (Windows):
  - Installer mendaftarkan Rak Baca untuk EPUB, MOBI, PRC, FB2, CBZ, PDF, DOCX, ODT, RTF, dan
    Markdown, sehingga dokumen bisa dibuka lewat klik kanan > Open with > Rak Baca. Bila jenis
    berkas itu sudah punya aplikasi bawaan pilihan pengguna, Windows tetap memakainya.
  - Seret berkas ke ikon atau jendela Rak Baca juga bisa. F11 = layar penuh.

Membuat ulang installer Windows:
  Cara 1 - otomatis lewat GitHub Actions (workflow "Rak Baca - uji & installer Windows"):
    jalankan dari tab Actions (Run workflow), lalu unduh artifact "rak-baca-windows".
    Workflow lebih dulu menguji semua format di Chrome; installer hanya dibuat bila uji lolos.
    Push tag rak-baca-v<versi> (mis. rak-baca-v1.0.1) untuk sekaligus membuat GitHub Release.
  Cara 2 - di komputer Windows (butuh Node.js 22+):
    1. Jalankan tools/build.sh (otomatis memperbarui desktop/app/index.html)
    2. Buka folder desktop di Command Prompt, jalankan:
         npm ci
         npm run dist:win
    3. Hasil ada di folder desktop/dist:
         Rak Baca Setup <versi>.exe   installer (pilih folder, pintasan desktop & Start Menu)
         Rak-Baca-Portable.exe        langsung jalan tanpa instal
  Installer belum ditandatangani (code signing), jadi Windows SmartScreen akan
  menampilkan peringatan "Windows protected your PC": klik "More info" > "Run anyway".
  Naikkan "version" di desktop/package.json setiap merilis versi baru.

Menguji setelah mengubah kode:
  sh tools/build.sh
  node tools/make-samples.js /tmp/contoh
  node tools/test-reader.js /tmp/contoh        (butuh paket playwright, atau playwright-core
                                                 dengan CHROME_PATH=<lokasi chrome>)

Aplikasi ini tidak memerlukan Claude untuk berjalan.
